# Student Money Tracker

## Overview
Student Money Tracker is a beginner-friendly Python finance tracker designed to help students manage their personal money.

## Features
- Add income
- Add expenses
- View transaction history
- Delete transactions
- Calculate balance
- Category-wise expense report
- Set and check monthly budget
- Set and check savings goal
- Financial summary
- Save data permanently
- Basic input validation
- Unit tests

## Technologies Used
- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- JSON file handling
- unittest

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python main.py
```

## How to Test
Open the project folder and run:

```bash
python -m unittest discover tests
```

## Project Structure
- main.py - main menu and program workflow
- income.py - income management
- expenses.py - expense and transaction management
- budget.py - budget management
- savings.py - savings goals
- reports.py - financial reports
- storage.py - data storage
- validation.py - input validation
- tests/ - testing files
- data/ - saved data
